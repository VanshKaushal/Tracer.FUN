PERSONAL MEANS PERSONAL

Your activity stays
on your side of the screen.

Trace saves history locally on your Windows account. It doesn't upload your activity, and it never records typed text, screenshots, clipboard content or browsing URLs.

Tracking is your choice from the first launch. Pause it, go incognito, export your history or delete it in Settings.

Local database: %LOCALAPPDATA%\Trace\trace.db
Trace does not encrypt this database. Protect your Windows account and device.

A FEW USEFUL ANSWERS

Before your first click.

What is Trace?

Trace is a free mouse activity tracker for Windows 10 and 11 on Intel and AMD x64 PCs. It shows cursor distance, clicks, scrolling, activity sessions and heatmaps in a dashboard, with a separate Trace Bar for quick access. The current release is an unsigned beta.

Is Trace really free?

Yes. All features in this release are free, with no account, payment details, subscription or trial period.

Do I need to install developer tools?

No. Use the Windows setup download above. Node.js, Rust, Git and Command Prompt are only relevant to people developing Trace.

What happens when I close the dashboard?

The collector keeps recording if tracking is enabled. Use Trace's system tray menu to pause or quit. Starting with Windows is optional and off until you choose it.

Will an update erase my history?

The installer keeps your local history. Uninstalling also leaves it on this PC so a reinstall can recover it. To remove activity history, use Settings → Delete all data before uninstalling. Export first if you want a copy.

Does cursor distance measure how far my mouse moves on my desk?

Pixels measure movement on your screen. Other units estimate that screen distance using display DPI; they don't measure physical travel across your desk.

How can I get help?

Report an issue on GitHub with your Windows version and what went wrong. Please don't attach your activity database or private exports to a public report.
